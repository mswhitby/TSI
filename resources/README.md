## URL handling

The explicit Pearson page field `resourceUrl` supplies `https://prd-s3.pearsonperspective.com/content/resources/learningresources/`. The page's `resources/js/common.js` concatenates that base with internal resource paths. Relative `lrURL` values resolve against this base; already-absolute HTTP/HTTPS external values remain unchanged.

Base-path evidence: [Pearson MATH01 page](https://tsia2.pearsonperspective.com/perspective/home?passCode=MATH01). Captured catalog context: TSIA2 code topics list conversation, `6ab2c616-e2f0-83ea-a012-f52ba1b60bba`. Basic QR was recovered from the live MATH01 response on November 3, 2026 because that attachment was unavailable. Source catalog counts were reconciled to 463 rows across all 12 catalogs in the workbook preparation.

Resource URL construction is validated. Individual media playback and legacy interactive compatibility have not been verified. No resource is required to complete this sample week, and no external content files are redistributed.
